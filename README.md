# Défi 2 SHS – Visualisation des effectifs étudiants (L2 MIASHS)
**Université Toulouse Jean Jaurès (UT2J)   Année 2025-2026**

Une application web interactive pour **visualiser et comparer les effectifs étudiants** en Licence 2 MIASHS (Méthodes Informatiques Appliquées aux Sciences Humaines et Sociales). 
Ce projet s’inscrit dans le cadre de mon deuxième défi et met en œuvre des **graphiques dynamiques** (barres, lignes) ainsi que des analyses comparatives par genre et par année.

---
## Objectifs pédagogiques :  
- **Manipuler des données réelles** (effectifs étudiants) via une API ou un jeu de données structuré (https://data.enseignementsup-recherche.gouv.fr/explore/assets/fr-esr-principaux-diplomes-et-formations-prepares-etablissements-publics/).
- **Créer des visualisations interactives** en utilisant **HTML, CSS et JavaScript pur**.
- **Travailler en équipe** pour produire une solution cohérente avec des parties individuelles et communes.
- **Appliquer les normes de codage** et documenter le projet de manière professionnelle.
---

---
## Contenu du projet :

### 🔹 Partie commune (collaborative)
- **Graphique en barres** : Évolution du nombre d’inscrits par année (2021-2025).
- **Graphique en ligne** : Tendances des effectifs sur la période.
- **Comparaison par genre** : Répartition femmes/hommes dans la formation.

### 🔹 Parties individuelles (1 par membre)
Chaque membre de l’équipe a proposé une **comparaison originale** des données comme vous pourriez le voir en sortie web sur le navigateur.

## Installation et utilisation : 

### Prérequis :
- Un navigateur web moderne (Chrome, Firefox, Edge).
- [VS Code](https://code.visualstudio.com/) + [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) (recommandé pour le développement).

### Lancement :

1. **Cloner le dépôt** :
   ```bash
   git clone https://github.com/ton-pseudo/nom-du-depot.git

2. **Ouvrir le projet dans VS Code**

3. **Lancer avec Live Server** :

Clique droit sur index.html > "Open with Live Server".
